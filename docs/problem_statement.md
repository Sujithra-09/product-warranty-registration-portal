\# Problem Statement



\## Product Warranty Registration Portal



Managing product warranty information manually can be difficult and may lead to data duplication, missing records, and difficulty in tracking warranty status.



The Product Warranty Registration Portal provides a web-based solution for registering and managing product warranty information.



The system allows users to register warranty details such as product name, product ID, customer name, and purchase date. Administrators can view, create, update, and delete warranty records through an admin dashboard.



The system also calculates the warranty expiry date and displays the current warranty status as Active, Expiring Soon, or Expired.



The application uses Java Spring Boot for backend processing, Thymeleaf/HTML for the web interface, Spring Data JPA for database operations, and MySQL for data storage.



\## Objectives



\- Provide an easy way to register product warranty details.

\- Store warranty information securely in a database.

\- Allow administrators to manage warranty records.

\- Validate required input fields.

\- Calculate warranty expiry dates automatically.

\- Display the current warranty status.

\- Provide role-based access for Admin and User.

\- Provide a health check endpoint for application monitoring.
